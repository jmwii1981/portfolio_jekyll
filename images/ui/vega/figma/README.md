# Vega demo source assets

Original icons and illustrations exported from the user-provided Figma file:
https://www.figma.com/design/YnFMeNV3LNNwtTkjMbNR1p/Proposed-Flows-Overview?node-id=40000010-290

Reference: “How to use Quick Actions in Dash vs Left Nav,” frame 40000010:290.
The reconstruction follows the Payments Manager+ dashboard, including its Inter typography, colors, card layout, navigation, quick actions, charts, and task illustrations. SVG intrinsic dimensions are preserved.

Source groups inspected: header 40000010:291; sidebar 40000010:308; tasks 40000010:514; greeting 40000010:611; quick actions 40000010:653; sales 40000010:816; distribution 40000010:870; trending services 40000010:923; trending products 40000010:1011.

The implementation is native HTML/CSS/JavaScript, not the production Vega component package. Tablet and phone arrangements are responsive adaptations because corresponding source frames were not provided. Secondary interactive states and forms are illustrative demo implementations, not claims of exact production behavior. All data is temporary, in-memory sample data; no payments, messages, or appointments are transmitted.

Files in this directory are Figma exports. Inter font files and their license live in /fonts. The larger preview and mini screens are defined in /scripts/vegaDemo.mjs and /styles/vega-demo.css.
