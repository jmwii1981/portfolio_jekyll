# Changelog

Notable changes to janmichael.io are recorded here. The project uses
[Semantic Versioning](https://semver.org/) for milestone releases.

## [Unreleased]

## [1.0.0] - 2026-08-07

### Added

- A complete portfolio experience with selected work, detailed case studies,
  professional background, perspectives, recommendations, contact options, and
  a standalone links page.
- Progressive enhancements for site search, navigation, consent handling,
  contact-form feedback, project browsing, and dynamically retrieved articles.
- Automated production builds, static-search validation, JavaScript regression
  tests, and generated-site audits in GitHub Actions.

### Changed

- Refined the responsive layout, typography, project presentation, secondary
  project navigation, metadata, and structured data across the site.
- Restored the original logo implementation and protected its optional path
  animation with a browser-support check.
- Added bounded network requests and retry-safe loading for contact, search, and
  perspectives features.

### Removed

- Toptal references from the public website.
- Obsolete icon assets and other repository housekeeping files that were no
  longer pertinent to the site.
